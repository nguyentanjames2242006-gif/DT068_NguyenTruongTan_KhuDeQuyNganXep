🌳 Hình ảnh cây

🔄 Phương pháp 1: Duyệt đệ quy

// Giáo trình: duyet_sau_de_quy(cay, goc)
void duyet_de_quy(int node) {
  ketqua.push_back(node); // Thăm nút
  for (auto child : con[node])
    duyet_de_quy(child); // Đệ quy từng con
}

📚 Phương pháp 2: Duyệt bằng ngăn xếp thông minh

// Giáo trình: duyet_khu_de_quy(cay, goc)
void duyet_stack(int root) {
  stack st; st.push(root);
  while (!st.empty()) {
    int u = st.top(); st.pop();
    ketqua.push_back(u); // Thăm
    for (i = con[u].size()-1; i>=0; i--)
      st.push(con[u][i]); // Push ngược!
  }
}

📖 Cơ sở lý thuyết — Giáo trình trang 129–130 (PDF 141–142)

Trích dẫn giáo trình (Mục 5.3.5):
"Mọi thuật toán đệ quy đều viết lại được bằng vòng lặp cộng một ngăn xếp, vì bản thân cơ chế đệ quy của ngôn ngữ cũng dùng ngăn xếp lời gọi. Kỹ thuật này cần đến khi độ sâu đệ quy vượt giới hạn của ngôn ngữ, như đã nêu ở mục 3.3."

1. Duyệt cây bằng đệ quy (Preorder — Duyệt trước)

Hàm duyet_sau_de_quy trong giáo trình (tên hơi gây nhầm, thực ra là duyệt trước):

# Python — Giáo trình def duyet_sau_de_quy(cay, goc): if goc is not None: print(goc, end=" ") # Thăm nút TRƯỚC for con in cay[goc]: duyet_sau_de_quy(cay, con) # Đệ quy từng con

2. Khử đệ quy bằng ngăn xếp (Stack)

Hàm duyet_khu_de_quy — thay đệ quy bằng vòng lặp + stack:

# Python — Giáo trình def duyet_khu_de_quy(cay, goc): st = [goc] while st: u = st.pop() print(u, end=" ") for con in reversed(cay[u]): # đảo để thứ tự duyệt không đổi st.append(con)
Chi tiết quan trọng (trang 142):
"Ngăn xếp lấy ra theo thứ tự ngược với thứ tự đưa vào, nên muốn giữ nguyên thứ tự duyệt của bản đệ quy, phải đẩy các con vào theo thứ tự ngược lại."

Ví dụ: con = [2, 3] → push 3 trước, rồi 2 → pop ra 2 trước ✓

3. Tại sao phải push ngược (reversed)?

Hành độngKhông đảoCó đảo (reversed) ✓
Con của nút 1: [2, 3] Push 2, Push 3
Stack: [3, 2] (đỉnh=3)		 Push 3, Push 2
Stack: [2, 3] (đỉnh=2)
Pop tiếp Pop 3 → thăm 3 trước ✗ Pop 2 → thăm 2 trước ✓

4. Cơ chế đệ quy và ngăn xếp lời gọi (Mục 3.3.4)

Mỗi lời gọi hàm chiếm một khung (frame) trên ngăn xếp lời gọi, chứa tham số, biến cục bộ và địa chỉ trở về. Bộ nhớ tỷ lệ với độ sâu cây đệ quy, không phải tổng số lời gọi.

Ngôn ngữGiới hạn mặc địnhCách mở rộng
Python1000 lời gọi lồngsys.setrecursionlimit(10**6)
C++~10⁵–10⁶ (tùy frame)Tăng stack size hoặc khử đệ quy

5. Biểu diễn cây

Cây tổng quát (general tree) biểu diễn bằng danh sách kề (adjacency list): con[i] = mảng các nút con của nút i. Mỗi nút có thể có bao nhiêu con tùy ý (1 ≤ n ≤ 100).

📝 Nhận xét tổng hợp

  1. Hai phương pháp cho kết quả giống nhau trên mọi test case, chứng minh tính đúng đắn của thuật toán khử đệ quy.
  2. Trick "reversed" (push con từ phải sang trái) là chi tiết then chốt giữ đúng thứ tự duyệt.
  3. Cả hai đều O(n) thời gian; stack tường minh có thể O(n) bộ nhớ trong trường hợp xấu (cây suy biến thành dây xích).
  4. Khử đệ quy quan trọng khi cây sâu (>10⁵ nút) vì tránh tràn call stack.
  5. Thử nghiệm thành công với cây 5, 20, 100 nút.
